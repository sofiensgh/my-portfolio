# Sofien Essghaier — Portfolio

Personal portfolio with a NieR:Automata-inspired YoRHa interface: boot sequence, CRT scanlines, light/dark themes and animated page transitions.

**Live:** https://sofien-essghaier.vercel.app

## Stack

- [TanStack Start](https://tanstack.com/start) (React 19, file-based routing, SSR)
- Tailwind CSS v4
- TypeScript
- Deployed on Vercel (via Nitro) — Netlify also supported

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

On Vercel the build emits `.vercel/output` through Nitro; elsewhere it builds for Netlify.
